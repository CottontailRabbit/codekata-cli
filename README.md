# codekata ⚔

**A terminal coding kata that hits back.** Fight bosses with code: every correct answer shakes the screen,
flashes, slams a giant `CRITICAL` onto it and drains the boss HP bar while an esports caster yells about your
combo. Problems are generated by ChatGPT (through the Codex CLI), answers are *executed* and judged, and a
debugger "killcam" replays your code line by line.

## Features

| | |
|---|---|
| **Modes** | Ranked (8-stage mix) · Type Rush (type code, WPM) · Kata (write 1–2 lines) · Quiz (read code, 4 choices) · **Robot SW exam track** (Python/C++) |
| **Languages** | Python, JavaScript, Rust, C++, Go |
| **Hit feel** | screen shake · flash · big-text slams · HP drain · combo tiers (3/5/7/10/15) · synthesized SFX · caster + analyst commentary |
| **AI problems** | ChatGPT via `codex exec` with a JSON schema, prefetched in the background (a batch takes ~30 s); the built-in bank serves instantly meanwhile |
| **Judging** | Python/JS answers are run against hidden tests (hard-coding fails). Other languages: normalized / regex / keyword match, then an AI "VAR review" |
| **AI validation** | generated kata answers are executed and broken ones dropped; output-prediction quiz answers are corrected from the real output |
| **Debugger** | `sys.settrace` killcam replay with NEW/CHANGED variable highlights, autoplay, step back/forward |
| **Logging** | every event (problem, submit, hit, AI latency, ranking push) in `~/.codekata/logs/*.jsonl`; `codekata log <sid>` shows a timeline |
| **Online ranking** | ranked runs upload to a shared GitHub repo (via `gh`) or a self-hosted `codekata serve` |
| **UI language** | English / 한국어 (`--en`, `--ko`, `L` in the menu, or `codekata config set ui en`) |

## Requirements

| | required? | used for |
|---|---|---|
| Python ≥ 3.9 | **required** | the game (standard library only, no pip dependencies) |
| [Codex CLI](https://github.com/openai/codex) logged in with ChatGPT | **strongly recommended** | AI-generated problems and the AI VAR review. Without it codekata runs on the offline bank only (~80 problems) |
| `node` | optional | executing JavaScript answers |
| `g++` | optional | C++ judging that compiles and runs answers |
| `gh` (logged in) | optional | the GitHub ranking backend |
| `aplay` / `paplay` / `afplay` | optional | sound effects |

> **Why ChatGPT and not Claude?** Claude subscription logins can't be used by third-party apps (that needs an
> API key), while the Codex CLI lets codekata use your existing ChatGPT login. No API key is needed.

### Set up the Codex CLI

```bash
npm install -g @openai/codex     # or: brew install codex
codex login                      # choose "Sign in with ChatGPT"
codekata doctor                  # should show ✔ codex (ChatGPT) login
```

## Install

```bash
pipx install git+https://github.com/CottontailRabbit/codekata-cli.git
# or from a clone
git clone https://github.com/CottontailRabbit/codekata-cli.git && cd codekata-cli && pipx install .   # (pip install --user . works too)
```

Then run `codekata`. A terminal of at least 90×32 with 256 colors is recommended.

## Usage

```bash
codekata                          # menu: 1 ranked / 2 rush / 3 kata / 4 quiz, ←→ language, L English/한국어
codekata play -m mix -l rust      # ranked mix in Rust
codekata rush -l python -n 3      # anything other than 8 stages is practice (not ranked)
codekata kata -l js
codekata quiz -l cpp
codekata debug file.py            # debugger killcam on any Python file
codekata stats                    # streaks, bests, per-language accuracy, sparklines
codekata log [sid] [--errors|--raw|-f]
codekata rank [-m mix] [-p day|week|all] [-l python]
codekata rank setup               # connect online ranking (github | http)
codekata auth [login]             # ChatGPT (Codex) login status / login
codekata config [key] [value]     # e.g. codekata config set ui en
codekata serve --port 8787 --token SECRET   # self-hosted ranking server
codekata doctor
```

Global flags (anywhere): `--en` `--ko` `--debug` (HUD + `~/.codekata/debug.log`) `--no-fx` `--no-sound`
`--no-color` `--offline`.

### Keys in game

| stage | keys |
|---|---|
| Type Rush | type the code (auto-indent), `Tab` = 4 spaces, `ESC` skip |
| Kata | `Enter` submit (3 tries), `Tab` hint (−40%), `ESC` skip |
| Quiz | `1`–`4`, 60 s timer, < 8 s = SPEED KILL |
| after a stage | `Enter` next, `d` debugger killcam, `q` quit |
| killcam | `→`/`←` step, `a` autoplay, `g`/`G` start/end, `q` close |

### Scoring

Combo multiplier `1 + 0.25 × combo` (max ×4) · crits for first-try / typo-free · speed bonuses · K.O. bonus per
boss · FLAWLESS (+3,000) for a no-miss, no-hint clear with all hearts. Grades SS / S / A / B / C / D.

## 🤖 Robot Software Engineer practical exam track (`exam` branch)

Practice the core pattern of the Korean *Robot Software Development Engineer* (로봇소프트웨어개발기사) practical
exam — **read a TXT input file, compute robot formulas, write the result file in exactly the required format** — in
Python or C++. Install this branch with `pipx install "git+https://github.com/CottontailRabbit/codekata-cli.git@exam"`.

```bash
codekata exam                      # ranked, 5 stages: quiz → kata → quiz → kata → real task (boss)
codekata exam -l cpp
codekata exam task                 # real tasks only (2 by default)
codekata exam task -t ik2 -l cpp   # pin one task
codekata exam quiz | kata
codekata exam list
```

| stage | what | judging |
|---|---|---|
| **quiz** | degrees vs radians, `atan2` argument order, `arange` end point, integer division, rounding rules, `-0.000`, signed bytes, heap direction, `grid[row][col]`, encodings, C++ `fixed`/`setprecision` … | every answer verified by running the code |
| **kata** | one-line formulas: FK/IK, cubic/LSPB/BBPB, PID, octile heuristic … | Python executed; **C++ compiled with g++ and run** against hidden tests |
| **real task** | `input.txt` is created in a work folder → `e` opens your editor (`$CODEKATA_EDITOR`/`$VISUAL`/`$EDITOR`/nano/vim) on `solution.py`/`.cpp` → `r` runs and grades | line-by-line diff against the reference output; value errors and format errors (decimals, separators) reported separately; ±1 in the last digit accepted |

Task keys: `e` editor · `r` run & grade · `h` hint (−30%) · `f` submit partial (≥ 50%) · `ESC` give up (shows the
model answer) · 25 minutes per task. Editing in another window (e.g. VS Code) and pressing `r` works too.

12 tasks with fresh random input every time: `fk2`, `ik2`, `mk2` (Jacobian velocity), `cubic`, `lspb`, `bbpb`,
`dijkstra`, `grid` (8-connected A*), `floyd`, `pid`, `can` (CAN frame parsing), `fan` (temperature hysteresis).
The Python and C++ model answers of every task produce identical output on 40 random inputs.

> Sources (researched 2026-10): Q-net notice "2026 Robot SW Development Engineer practical exam" (applies from the 3rd
> engineer session of 2026; personal PCs not allowed) and candidates' study notes (task-type, ~4–5 h, exam-room PC with
> Visual Studio · PyCharm · Excel, C · C++ · Python). Check the official PDF for the exact environment.

## Online ranking

Only ranked runs (8 stages) are uploaded.

* **GitHub** (no server): `codekata rank setup` → `github` → a shared repo such as `you/codekata-ranking`.
  Each player writes `ranking/<login>.json` with their own `gh` login; add friends as collaborators.
* **HTTP**: run `codekata serve --token SECRET` somewhere (SQLite, standard library), then `rank setup` → `http`.

Failed uploads are retried on the next sync. There is no anti-cheat — it's a game among friends.

## Data

Everything lives in `~/.codekata/` (override with `CODEKATA_HOME`): `config.json`, `history.json`, `logs/`,
generated sound effects. `CODEKATA_SEED=<n>` makes runs deterministic (useful for testing).
